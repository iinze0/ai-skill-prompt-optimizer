# Prompt Optimizer

Improve prompts for clarity, specificity, and better AI responses.

## Core Workflow

1. Analyze the original prompt: goal, context, constraints.
2. Identify weaknesses (vague, missing examples, poor structure, conflicting instructions).
3. Rewrite with:
   - Clear role / persona if helpful
   - Specific output format
   - Step-by-step instructions when complex
   - Examples (few-shot) if beneficial
   - Constraints and edge cases
4. Provide the optimized version plus a short explanation of changes.
5. Optionally offer 1-2 variations.

## Best Practices

- Be specific about desired output length and style.
- Use delimiters for sections.
- Prefer positive instructions over negative when possible.
- Test iteratively.
